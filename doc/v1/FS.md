四象限任务管理器，按天管理「重要 / 紧急」两个维度的四类任务，纯前端实现，可经 Capacitor 打包为安卓 App。

## 功能列表
### P0：核心功能
网页版四象限主视图：2×2 网格布局（I 重要且紧急 / II 重要不紧急 / III 紧急不重要 / IV 不重要不紧急）。手机端安卓 APP 改为 1×4 布局。四象限背景颜色：I 红 / II 蓝 / III 黄 / IV 绿
日期管理：默认当天；日期选择器切换任意日期，各日期数据相互独立
任务增删改：
- 每个象限提供「＋ 添加任务」按钮
- 单击任务文本进入编辑
- 删除按钮直接删除（无回收站，删除即永久）
四象限、日期、任务增删改、勾选、拖拽、持久化、统计、JSON 导入导出
完成勾选：checkbox 切换完成状态；完成态文字删除线 + 降低透明度
拖拽：同一象限内可以拖动任务顺序；跨象限也可以拖动任务所处象限位置
网页版/APP同步：任何变更立即写入同步容器
### P1：次要功能
亮 / 暗主题切换（UI 设置，不进入用户数据）
导出格式：导出全部用户数据为 .json 文件下载（离线备份通道），同时也支持导出为markdown / PDF文件。网页版Ctrl+S自动保存三种格式的文件，移动端需要手动选择保存类型（包括第四种选择，包含三种格式的.zip压缩包）
导入功能：选择本地 .json 文件，合并模式替换本地数据（如果某一任务的象限信息、文本内容和已有任务完全一致，不做插入操作）。如果JSON文件格式有误，终止导入操作
勾选与统计：完成 / 取消完成后，顶部统计（已完成 / 总数 / 完成率）与勾选状态一致
### 非功能需求
纯原生实现：HTML / CSS / JS，无框架、无构建步骤、无 npm 依赖；沿用 var + IIFE 风格（兼容 Capacitor WebView 与 file:// 场景）
性能：单日 ≤100 条任务时操作流畅；渲染与保存采用防抖合并
兼容：现代浏览器 + Capacitor WebView；安卓移动端（≤600px）可用
### 非目标（本期明确不做）
给后续开发者（含 Claude Code）的硬约束：任何超出以下边界的功能需求一律拒绝或移入后续迭代，不得自行添加。
不做账号：无登录、无注册、无手机短信验证、无微信登录、无 Token / JWT、无任何网络认证请求
不做协作：无共享、无多人、无权限、无邀请
不做提醒：无通知、无推送、无日程提醒、无到期提醒

## 验收标准
### P0：核心功能
首次打开：默认显示当天，四象限空状态渲染正常，无报错，生成本期用户数据 key
默认显示上次数据：打开时默认显示当天的上一版任务内容
拖拽：同象限排序与跨象限移动均生效，刷新后顺序保持
日期隔离：A 日期新增 / 修改任务不影响 B 日期
移动端：≤600px 单列展示，添加、勾选、编辑、删除可用
### P1：次要功能
导入导出：导出文件可下载且可重新导入；覆盖导入后数据被替换；非法 JSON 被拒绝且原数据不变
勾选与统计：完成 / 取消完成后，顶部统计（已完成 / 总数 / 完成率）与勾选状态一致

## 边界情况
### P0：核心功能
空日期：无数据的日期返回四象限空数组，正常渲染空状态
空任务文本：trim 后为空则拒绝创建并提示
超长文本：允许换行完整显示，移动端不溢出、不截断
大量任务：单日 ≥200 条时渲染 / 保存仍可用，不允许卡死或丢数据
日期边界：跨年 / 跨月切换正确（YYYY-MM-DD 格式化，不出现 2026-13-01 类错误）
首次启动无任何数据：正常初始化，不报错
### P1：次要功能
非法导入：JSON 解析失败或结构不符（非对象、缺象限键）→ 拒绝导入，保留现有数据，给出错误提示
覆盖导入误操作：导入前二次确认，并提示「建议先导出备份」
